
## NppPyInline: Калькулятор и Python прямо в Notepad++
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**NppPyInline** — это среда выполнения Python прямо внутри Notepad++. Вы пишете код в текстовом редакторе notetab++ между маркерами `_beg_` и `_end_`  и запускаете его одной командой. Результаты вычислений появляются на тех же строках или в конце блока.

Это не замена полноценному IDE. Это инструмент для быстрых сценариев, где не хочется переключаться на консоль, открывать Jupyter Notebook или писать отдельный `.py` файл.

## Когда это полезно

- **Посчитать что-то с промежуточными переменными** — мощный калькулятор с памятью
- **Быстро протестировать небольшой фрагмент кода** — не создавая отдельный файл
- **Обработать данные прямо в текстовом файле** — результат тут же, рядом с исходными данными
- **Сделать прототип на коленке** — не выходя из Notepad++

## Как это выглядит

**Пример 1: Простые вычисления**
Находим гипотенузу прямоугольного треугольника и вычисляем синусы углов.
```python
_beg_
a = 5
b = 50

# ? - оператор печати 
c = (a**2 + b**2)**0.5 ?.4 50.2494

# out() выводит данные единым блоком после end
out("Гипотенуза = {:.2f}".format(c))

sin_a = a / c
out("sin_a = {:.5f}".format(sin_a))

sin_b = b / c
out("sin_b = {:.5f}".format(sin_b))
_end_
# > Гипотенуза = 50.25
# > sin_a = 0.09950
# > sin_b = 0.99504

```
